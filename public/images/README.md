# Image Assets

เก็บรูปที่ใช้กับข้อมูลจาก API ไว้ที่นี่ในรอบแรก

โครงสร้างที่แนะนำ:

- `public/images/projects/`
- `public/images/certificates/`
- `public/images/activities/`

ตัวอย่างการอ้างอิงในข้อมูล:

- `/images/projects/project-cover.jpg`
- `/images/certificates/certificate-001.jpg`
- `/images/activities/activity-001.jpg`

แนวทางนี้ช่วยให้เริ่มทำ API และหน้า admin ได้ก่อน โดยยังไม่ต้องทำระบบ upload รูป
